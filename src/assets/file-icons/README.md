# Icon loại file

Nguồn: [Material Icon Theme](https://github.com/material-extensions/vscode-material-icon-theme) (MIT, xem `LICENSE`).

Đã chỉnh sửa:
- Đổi màu sang màu thương hiệu: `pdf.svg` (Adobe `#fa0f00`), `word.svg` (`#185abd`), `excel.svg` (từ `table.svg`, `#107c41`), `powerpoint.svg` (`#c43e1c`).
- `file.svg` là `document.svg` đổi sang xám `#90a4ae`; `text.svg` = `document.svg`; `code.svg` = `console.svg`.
- Các file còn lại giữ nguyên.

Tên sản phẩm/logo thuộc về chủ sở hữu tương ứng.
